# Corner Breakfast Vue Components Lesson

A class example that uses the Corner Breakfast order page to practice splitting a screen into Vue components.

Status: practice project

## Learning Objectives

After completing this example, you will know how to:

- Split the order page into a menu card component and a cart component
- Pass data down with props and notify the parent with emit

## Course Unit

- Course: Hands-on Vue for Beginners
- Lesson: Week 3
- Prerequisites: Vue basics from Week 2

## Tech Stack

- Vue 3
- Vite 6

## Getting Started

### Requirements

- Node.js 22 or later
- pnpm 10

### Installation

```bash
git clone https://github.com/zaocan/breakfast-vue-lesson.git
cd breakfast-vue-lesson
pnpm install
pnpm dev
```

Open http://localhost:5173 in your browser; once you see the menu, it is running.

## Starter and Solution

- Starter (follow along): `starter`
- Solution (reference answer): `solution`

Switch to the starter version:

```bash
git switch starter
```

## Usage

1. Open `src/components/MenuCard.vue` and follow the lesson steps.
2. Save the file and check the browser for one card per dish.
